# What a good final output contains

The existing file `price-lists/outputs/price-list.md`, edited in place.

Must contain:
- A4 paper, box: cost 196, price 245.
- Toner TN-240: cost 548, price 685.
- Desk lamp: cost 252, price 315.
- Whiteboard markers, 10-pack (cost 64, price 80) and Notebook A5 (cost 28, price 35) unchanged.
- The valid-from line changed to the new date.

Must not contain:
- A second price list file or a copy beside the original in `outputs/`.
- Changed prices for the two items the supplier did not mention.
